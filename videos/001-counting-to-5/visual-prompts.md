Append the config `style.image_suffix` to EVERY beat. 9:16, one clear subject, **no
text in image** (numbers are added as overlays). **Pass Willow's model sheet as a
reference image on every beat** so she's identical. Generate with Higgsfield
`nano_banana_2`, aspect "9:16".

  excited smile, curious peek pose, empty soft pastel room — _motion: gentle peek-in,
  ears bounce_

- **B5:** Willow jumping with joy beside FIVE red apples in a neat row, sparkly tail,
  confetti — _motion: happy jump, sparkles ✨_
- **B6 (payoff):** Willow front-and-center waving goodbye, big smile, sparkle tail,
  warm pastel background — _motion: slow pull-out, friendly wave_
